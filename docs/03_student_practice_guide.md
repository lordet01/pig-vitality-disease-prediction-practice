# 학생용 종합실습 안내

## 미션

같은 데이터로 재현 가능한 질병 조기경보 연구결과 1세트를 완성한다.

## 1단계: 연구질문과 분석기준 작성 - 5분

- 예측대상과 예측범위를 한 문장으로 작성한다.
- 관측단위가 돼지가 아니라 `개체-일`임을 기록한다.
- 제외 기준과 주평가지표를 실행 전에 정한다.
- 결과가 진단이 아니라 선별 위험도임을 명시한다.

## 2단계: 원자료 품질 확인 - 8분

다음을 코드로 출력하고 4문장으로 보고한다.

- 파일별 행·열 수와 ID 수
- `(pig_id, observation_date)` 중복 수
- 열별 결측 수와 비율
- `valid=False` 및 `qc_note` 분포
- 돈방별 카메라 커버리지
- 메타데이터와 매칭되지 않는 ID

## 3단계: 라벨 생성 원리 설명 - 5분

`clinical_onset_date`로부터 `disease_next_3d`를 어떻게 만들었는지 설명한다. 다음 열이 모델 입력에 들어가면 안 되는 이유를 적는다.

- clinical_onset_date
- confirmation_date
- treatment_date
- recovery_date
- days_to_onset

## 4단계: 탐색적 분석 - 8분

다음 중 두 가지 이상을 시각화한다.

1. 임상발현 전 7일간 활력도 평균 궤적
2. 양성·음성의 `vitality_delta_3d` 분포
3. 온도와 활동시간의 관계를 돈방별로 표시
4. 카메라 커버리지 구간별 결측률

## 5단계: 모델 비교 - 12분

- M0: 나이, 체중, 온도, 습도, 돈방
- M1: M0 + 당일 활력도와 행동지표
- M2: M1 + 최근 3일 변화량

train으로 학습하고 validation으로 임계값을 선택한다. test는 마지막에 한 번 평가한다.

## 6단계: 운영 기준 결정 - 7분

다음 중 하나를 선택해 임계값을 정한다.

- validation 민감도 80% 이상
- 돼지 100두·일당 경보 5건 이하
- 미탐 비용을 오탐 비용의 5배로 가정한 총비용 최소화

선택 이유와 예상되는 현장 업무량을 기술한다.

## 7단계: 결론 작성 - 5분

1. 데이터: 분석 표본, 질병 이벤트, 제외 건수
2. 결과: test AUPRC와 민감도, 경보량
3. 활용: 어떤 개체를 먼저 관찰할 것인지
4. 한계: 합성데이터, 라벨 지연, 외부검증 부재
