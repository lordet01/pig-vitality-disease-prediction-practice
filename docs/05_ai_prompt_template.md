# AI 분석 요청 프롬프트 템플릿

## 역할

너는 반복측정 축산 연구자료를 분석하는 Python 보조자다. 결정을 대신하지 말고 검증 가능한 코드와 점검 질문을 제공하라.

## 연구 맥락

- 관측단위: 개체-일
- 목표: 향후 1~3일 이내 수의사 확인 질병 위험 선별
- 목표열: `disease_next_3d`
- 자료구분: 시간순 `train`, `validation`, `test`
- 주지표: AUPRC

## 요청

`practice_dataset.csv`를 읽고 다음 작업을 단계별 함수로 작성하라.

1. 행·열·결측·중복·양성률 확인
2. 미래정보와 식별자를 입력변수에서 제외
3. train에서 로지스틱 회귀 학습
4. validation에서 목표 민감도 80%를 만족하는 임계값 선택
5. test에서 AUPRC, AUROC, 민감도, 특이도, PPV, 100개체-일당 경보 수 계산
6. 예측확률 분포와 precision-recall curve 저장

## 제약

- 무작위 행 분할 금지
- `pig_id`, 날짜, target, split은 모델 입력 금지
- test를 임계값 선택에 사용 금지
- 원본 CSV 수정 금지
- 실행하지 않은 수치 생성 금지
- 코드마다 입력, 출력, 실패 조건 설명

## 검증 요청

- 사용된 열 목록을 출력하라.
- 각 split의 양성 수를 출력하라.
- test 평가 전 임계값이 고정되었음을 코드 구조로 보여라.
- 데이터 누수 가능성을 마지막에 별도 목록으로 제시하라.
