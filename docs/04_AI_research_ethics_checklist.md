# AI 연구윤리 체크리스트

## 데이터 입력 전

- [ ] 이 데이터는 합성·공개·내부·개인정보 중 어디에 해당하는가?
- [ ] 외부 AI 서비스에 입력할 권한이 있는가?
- [ ] 농장명, 위치, 사람, 계약정보, 미출원 기술이 제거되었는가?
- [ ] 재식별 가능성을 검토했는가?

## 코드와 분석

- [ ] AI가 작성한 코드의 입력·출력을 설명할 수 있는가?
- [ ] 작은 예제와 수작업 계산으로 검산했는가?
- [ ] 공식 문서에서 함수의 동작을 확인했는가?
- [ ] 미래정보와 치료정보가 입력변수에 들어가지 않았는가?
- [ ] 동일 개체의 반복측정으로 인한 누수를 확인했는가?
- [ ] 유리한 결과가 나올 때까지 제외·임계값을 변경하지 않았는가?

## 결과와 문서

- [ ] 예측을 진단 또는 인과관계로 표현하지 않았는가?
- [ ] 정확도 외에 AUPRC, 민감도, 경보량을 보고했는가?
- [ ] 오탐·미탐이 동물과 작업자에게 미치는 영향을 설명했는가?
- [ ] AI가 만든 참고문헌을 원문에서 확인했는가?
- [ ] 사용한 도구, 목적, 검증, 수정 내역을 기록했는가?
- [ ] 최종 결과를 연구자가 검토하고 책임지는가?

## AI 사용 공개문 예시

본 실습에서는 Python 코드 초안과 오류 설명을 위해 생성형 AI를 사용하였다. 입력자료는 실제 농장과 무관한 합성데이터로 제한하였다. AI가 제안한 코드는 연구자가 직접 실행하고, 출력 범위·데이터 분할·미래정보 누수를 검토하여 수정하였다. 연구질문, 분석기준, 결과 해석과 최종 문서에 대한 책임은 작성자에게 있다.
